# 计算传播学 · 数字哀悼研究数据

「数字哀悼与舆论反转」期末研究使用的公开平台数据。

## 结构

```text
data/
├── liwen/
├── qiongyao/
├── zhangxuefeng/     # dy（抖音）/ bili（B站）
└── zhouhaimei/
```

每位研究对象按四个阶段组织：

- `T1_生前争议期`
- `T2_死亡爆发期`
- `T3_哀悼持续期`
- `T4_长期记忆期`

每个阶段包含 `search_videos`、`search_comments`、`search_creators` 三类 CSV 与 XLSX。

## 使用说明

数据采集自公开社交媒体平台（抖音、B站等），仅供课程研究复现与学术讨论使用。

文件中的昵称、用户 ID、头像链接、评论文本等属于平台用户信息。请勿用于人肉、骚扰、商业用途或其他非研究目的；公开引用时请遵守平台条款与学术伦理。

本仓库不包含原始登录凭据、Cookie 或 API 密钥。
